# 股票型基金与混合型基金

## 股票型基金
股票型基金规定将 80% 以上的基金资产投资于股票。它的收益和风险都最高，净值波动大，适合风险承受能力强、投资期限较长的投资者。

## 混合型基金的分类
混合型基金可以灵活配置股票和债券，按股票仓位高低分为几类：
- 偏股型：股票仓位通常 60% 到 80%，风险接近股票基金。
- 平衡型：股票仓位 40% 到 60%，股债均衡，波动适中。
- 偏债型：股票仓位 20% 到 40%，以债券打底、少量股票增强。
- 灵活配置型：股票仓位 0 到 95%，由经理灵活调整。

## 风险收益特征
从风险由低到高排列：偏债型 < 平衡型 < 偏股型 < 股票型。收益潜力则大致相反。投资者应根据自身风险承受能力选择对应的仓位水平。

## 如何选择
1. 看股票仓位：仓位越高，波动越大，先确定自己能承受多大回撤。
2. 看基金经理：主动权益类产品业绩与经理高度相关，关注其长期业绩和风格稳定性。
3. 看持仓集中度：持仓越集中的基金，单一个股波动对净值影响越大。
4. 看历史回撤：最大回撤能直观反映基金的波动幅度，用来判断是否匹配自身承受力。
